# Grill with docs

Run the `grill-me` interview and the `domain-modeling` procedure together.

As each answer settles a term, record it in the glossary. As each answer settles a decision with real alternatives, record it as an ADR. Write both in the formats `domain-modeling` defines, in the project's existing docs location.

Stop when `grill-me` reaches its stopping condition and every settled term and decision has been written down.
