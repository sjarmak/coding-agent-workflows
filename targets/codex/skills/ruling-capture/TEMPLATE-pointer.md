# Pointer-line template

Copy this line into the main instructions file and replace the bracketed text:

```markdown
- [Rule topic]: [one-line statement of what the rule is about]; see `[repository-relative/path-to-owning-document.md]`.
```

Example shape:

```markdown
- File-deletion safety: list each target before deleting it; see `docs/conventions/file-deletion.md`.
```

Keep this pointer to one line. Put the complete ruling, reasoning, exceptions,
and operating detail in the linked document.
